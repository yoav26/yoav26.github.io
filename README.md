# Yoav Orchen - Personal Portfolio

A modern, responsive personal portfolio website showcasing my work, skills, and projects.

## 🚀 Features

- **Responsive Design**: Optimized for all devices and screen sizes
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Interactive Navigation**: Smooth scrolling and active state indicators
- **Project Showcase**: Detailed project cards with technology tags
- **Skills Section**: Organized display of technical skills and expertise
- **SEO Optimized**: Meta tags and structured content for better search visibility

## 🛠️ Technical Stack

- **HTML5**: Semantic markup and accessibility features
- **CSS3**: Modern styling with Flexbox and Grid layouts
- **JavaScript**: Interactive features and smooth animations
- **Responsive Design**: Mobile-first approach with CSS media queries

## 🚀 Getting Started

1. Clone or download the repository
2. Open `index.html` in your web browser
3. Navigate through the sections using the navigation menu
4. Explore projects and skills sections

## 📝 Customization

### Adding New Projects
Edit the project cards in `index.html`:
```html
<div class="project-card">
    <div class="project-title">Your Project Name</div>
    <div class="project-description">Project description here</div>
    <div class="project-tech">
        <span class="tech-tag">Technology 1</span>
        <span class="tech-tag">Technology 2</span>
    </div>
    <a href="project-url" target="_blank">View Project →</a>
</div>
```

### Updating Skills
Modify the skills section in `index.html` or `about.html`:
```html
<div class="skill-category">
    <h3>Category Name</h3>
    <ul class="skill-list">
        <li>Skill 1</li>
        <li>Skill 2</li>
    </ul>
</div>
```

### Styling Changes
Edit `styles.css` to customize colors, fonts, and layouts.
